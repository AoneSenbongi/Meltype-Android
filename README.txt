Meltype Android 1.1.0

Meltypeを、Androidのキーボードで。
日英を切り替えずに入力でき、変換の区切りもその場で直せます。

・欲しい候補がなければ、打ち直す前に文節を調整
・英語と誤判定された入力も、日本語の候補へ戻せる
・次の文字の予測に合わせて、隣のキーとのタップ判定を調整
・コピー内容は候補欄から1タップで貼り付け。数字欄でも使える

Android 8.0以降のarm64端末向け。QWERTYとGODAN（五段）のローマ字入力に対応します。
雪代／Yukishiro氏のMeltype 1.3.0を基に、OSS版MozcとAndroid向けの操作を組み合わせた非公式版です。
1.1.0は端末内zenzを同梱し、既定OFFで配布します。

ダウンロード
https://github.com/AoneSenbongi/Meltype-Android/releases

主な機能

1. 変換の区切りを直して、欲しい候補を選ぶ

   変換結果が違っていたら、打ち直す前に読みの範囲を直せます。
   Shiftを2回押して固定し、左右矢印で文節を縮めたり広げたりします。
   変更した範囲全体の候補を取得し直すため、最初の区切りで見つからなかった語も選べます。

   に｜だい → 範囲を「にだい」へ広げる → 荷台
   camera  → Shift＋左・右で日本語の読みに戻す → カメラ

   英語と判定された部分も、ローマ字として読めれば日本語に直せます。
   候補をタップすると選んだ文節まで確定し、後ろの文節は編集を続けられます。

   操作の図：docs/images/android-1.0.0-boundary.svg
   実際の画面：docs/images/android-1.0.0-romaji.png

2. 次の文字の予測に合わせて、タップ判定を調整する

   キーの見た目を変えず、次に来そうな文字へ隣接キーとの境界を調整します。
   同じ段の文字キーだけを対象とし、キー中央や操作キーの判定は保ちます。
   調整条件と入力欄ごとの扱いは利用ガイドに記載しています。

3. コピー内容を候補欄から1タップで貼り付ける

   コピー後に初めてキーボードを開くと、候補欄にコピーしたテキストを表示します。
   タップすると貼り付けられ、数字・小数・電話番号の専用配列でも使えます。
   閉じた後や入力・確定後は同じコピーを再表示しません。
   後から貼り付けたい場合は、▤からクリップボード履歴を開けます。

   数字配列の画面：docs/images/android-1.0.0-numeric.png

4. 日英混在入力を、片手表示や辞書で使いやすくする

   日本語・英語を自動判別し、日本語は端末内のMozcでライブ変換します。
   英語専用入力、右寄せ・左寄せの片手表示、文字キー長押しの数字・記号に対応します。
   自分の単語や定型文を登録し、Simeji JSONとタブ区切りの辞書も取り込めます。

5. GODAN配列

   Gboardと同じ5段3列の母音・子音配列で、大きなキーのままローマ字入力できます。
   濁音・半濁音・数字・句読点・長音符はフリックで入力します。
   中央の文字キーの左右に操作列を置きます。左に戻す・←・記号・かな/A・QWERTY、右に⌫・→・空白・↵（下2マス）、中央の最下段に「大⇔小」を置きます。空白キーは→と↵の間です。
   初回はQWERTYのみで始まります。アプリ設定は「基本設定」と「キーボード」に分かれ、「キーボード」→「キーボード配列」でGODANを選ぶとGODANとQWERTYの両方を使えます。GODANの「QWERTY」とQWERTYの「五段」で行き来でき、QWERTYのみのときは「五段」キーは表示されません。選んだモードは次回も使います。中央の下段の「大⇔小」は、タップで は→ば→ぱ→は のように濁点/半濁点/小書きを順に切り替え、上フリックで小書き/通常、左フリックで半濁点、右フリックで濁点を入力します。文字キーを押すと、上下左右のスライド候補がキーの上にフローティング表示されます。「戻す」は未確定なら取り消し、確定済みなら Ctrl+Z を送ります。「かな/A」は未確定文字をかな⇔アルファベットに切り替え、記号配列からは「五段」でGODANへ戻ります。

   画面：docs/images/android-godan.png、docs/images/android-godan-flick.png、docs/images/android-settings-basic.png、docs/images/android-layout-setting.png
   キーの割り当て：docs/ANDROID_USER_GUIDE.md

1.1.0の追加機能

・端末内zenzによる誤字の候補評価（既定OFF）
・文字キーと句読点キーの上フリック
・文字種5項目だけの上フリックメニュー。取消などの旧操作は削除
・型番の英数字を保持し、曖昧な末尾は別表記を候補として提案
・端末の操作領域に合わせた下部余白
・設定画面からGitHubの最新Releaseを開く更新案内

zenzは設定の「端末内AI／未変換の誤字を見直す」をONにして使います。
モデルは同梱され、インターネットへ入力を送りません。誤選択や準備・推論の待ち時間があり、長期精度は未確認です。
型番末尾の別表記は、自動置換せず候補を選んだときに反映します。

使い始める

1. ReleasesからMeltype-Android-1.1.0.apkを取得し、開いてインストールします。
2. Meltypeアプリの「キーボードを有効にする」で有効にします。
3. 「キーボードを選ぶ」でMeltypeを選び、試し書き欄で入力します。

元のキーボードにはAndroidの入力方法切替から戻せます。

基本操作

・空白：変換、または空白の入力
・確定キー：未確定文字を確定。未確定文字がなければ入力先の改行・送信・次へ
・候補をタップ：選択文節まで確定し、後続は編集を継続
・左右矢印：文節を選択。未確定文字がなければ入力先のカーソルを移動
・Shiftを2回：固定。固定中の左右矢印で文節の範囲を変更。再度Shiftで解除
・自動・カナ・日英キーの上フリック：ひらがな・カタカナ・半角カタカナ・全角/半角英数字
・123／ABCの長押し：追加記号
・削除の長押し：連続削除
・▤：クリップボード履歴。×でキーボードに戻る
・片手：右寄せ・左寄せ・全幅を切り替え

データとプライバシー

入力・変換・学習は端末内で処理し、インターネット権限は要求しません。
通常の変換学習では、確定した語句等を端末内へ保存する場合があります。
学習の停止はMeltypeアプリで切り替えます。
パスワード欄や、入力先が学習禁止を指定した欄では個人向け処理を制限します。
クリップボード履歴はテキスト最大10件・1時間をメモリー内に保持し、機密指定の項目は保持しません。
誤字の削除前後の文字を収集する機能はありません。
保存対象と除外条件はSECURITY.mdを参照してください。

対応範囲

・Android 8.0以降のarm64。x86_64はエミュレーター検証用
・かな配列（12キー）のフリック入力・音声入力・クラウド同期：未対応。GODAN配列のフリックは対応
・Gboardの辞書・学習履歴との連携、Androidの再変換UI、GitHubタイトル候補：未対応
