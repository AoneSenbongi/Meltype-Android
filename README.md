# Meltype Android

ローマ字で日本語と英語を混ぜて入力できる、非公式のAndroidキーボードです。[雪代／Yukishiro氏のMeltype](https://github.com/yksr-melt/Meltype)を基に、OSS版Mozcによるライブ変換とAndroid向けの操作を組み合わせています。

**Android版0.5.0のソースです。** 本家Meltype 1.3.0の入力コア・辞書を取り込んでいます。本家とAndroid版の版番号は別です。APKの公開状況は[Releases](https://github.com/AoneSenbongi/Meltype-Android/releases)で確認してください。

[導入](#導入) · [基本操作](#基本操作) · [追加機能の設定](#追加機能の設定) · [プライバシー](#プライバシー) · [開発と検証](#開発と検証)

## できること

- 日本語・英語を自動判別し、入力先のアプリにライブ変換を表示します。
- 変換候補をタップして選んだ文節まで確定し、後ろの文節は続けて編集できます。
- 次に来る文字の予測で、同じ段の隣接キーのタップ判定を最大30％調整します。配列やキーの見た目は変えません。
- Shift固定中の左右矢印で文節を伸縮できます。
- コピー後の最初のキーボード表示で、コピー内容を1タップで貼り付けられます。閉じた後や入力・確定後には同じコピーを再表示しません。
- 数字・小数・電話番号の専用配列でも、初回のコピー候補とクリップボード履歴を利用できます。
- 単語登録、辞書の取り込み、句読点の選択、片手表示に対応しています。

0.5.0では、計算結果・略入力・予測などの1.3.0機能を設定画面とタッチ操作へ接続しました。[変更点と検証範囲](docs/ANDROID_RELEASE_0_5_0.md)にまとめています。

## 導入

対象は**Android 8.0以降のarm64端末**です。x86_64はエミュレーターでの検証用です。フリック入力には対応していません。

1. [Releases](https://github.com/AoneSenbongi/Meltype-Android/releases)から通常版のAPKをダウンロードして開きます。Androidに求められた場合は、ダウンロードに使ったアプリからのインストールを許可します。
2. Meltypeアプリを開き、「キーボードを有効にする」で有効にします。
3. 「キーボードを選ぶ」でMeltypeを選び、アプリ内の試し書き欄で入力します。

元のキーボードにはAndroidの入力方法切替から戻せます。自動更新はありません。同じ署名の通常版0.3.0以降からは上書き更新する構成です。0.2.0は署名が異なります。削除すると辞書・学習データも消えるため、更新に失敗した場合はすぐにアンインストールせず、署名と版番号を確認してください。

| 配布物 | 用途 |
| --- | --- |
| 通常版 | 日常の入力用。誤字の編集記録を収集する画面を含みません。 |
| 学習用 | 通常版とは別アプリ。利用者が開始した場合だけ編集記録を7日間収集する開発・検証用です。USB取得のためデバッグ可能です。 |

## 基本操作

| 操作 | 動作 |
| --- | --- |
| 文字を入力 | 日英自動判別とライブ変換 |
| 候補をタップ | 選択文節まで確定。後ろの文節は編集を継続 |
| 空白 | 未確定文字の変換、または空白の入力 |
| 確定・改行 | 未確定文字を確定。未確定文字がなければ入力先の改行・送信・次へ |
| Shiftを2回 | 大文字固定。もう一度押して解除 |
| Shift固定中に左右矢印 | 選択文節を縮小・拡大 |
| 日英・カナ・自動キーをタップ | 英語専用・自動判別、または未確定文字のカタカナ切替 |
| 日英・カナ・自動キーを長押し | 日本語変換、取消、文字種変更、部分確定などの操作メニュー |
| 123・ABCを長押し | `*`、`=`、角括弧などの追加記号 |
| 文字キーを長押し | キー右上の数字・記号 |
| 削除を長押し | 連続削除 |
| ▤ | クリップボード履歴。×で元の配列へ戻る |
| 片手表示ボタン | 右寄せ・左寄せ・全幅の順に切替 |

クリップボードはテキストを最大10件・1時間、メモリー内だけに保持します。「全消去」で削除できます。数字欄に貼り付けられる文字は入力先アプリの制限に従います。画像・URI・機密指定のクリップと、数値パスワードを含むパスワード欄では利用しません。

## 追加機能の設定

Meltypeアプリの**「1.3.0の入力機能」**で切り替えます。変更後は入力欄を開き直してください。新しい任意機能は既定OFFで、従来の候補表示・表示どおりの確定・括弧内への移動は既定ONです。

| 機能 | 使用例・操作 |
| --- | --- |
| 計算候補 | `1+2*3`を変換し、`7`を選択 |
| 子音の略入力 | `ast`から「明日」を選択 |
| 語句・英単語の予測 | 候補をタップして確定。保存された語句は長押しで学習から削除 |
| 英字の社名・サービス名 | 予測と併用し、読みから`Xiaomi`などを選択 |
| 読みからクリップボード変換 | 「ぺーすと」「くりっぷぼーど」を変換してコピー内容を選択 |
| 記号・空白 | 全角括弧、角括弧、スラッシュ、かなの後のw、全角空白など |
| 入力操作 | 取消の段階戻し、選択文節だけの文字種変更、英字中心の入力など |
| 学習・表示 | 前の文脈で分ける英日学習、入力したローマ字の表示、打鍵間隔だけの記録 |

[1.3.0機能の対応一覧](docs/ANDROID_1_3_0_FEATURES.md)に全22項目の適用範囲を記載しています。GitHubタイトルの取得とPC固有のトレイ・ホットキー等は移植していません。LLMによる誤字検出・自動変換は今回の対象外です。

## 辞書と誤字補正

設定画面の「単語登録・辞書の取り込み」で単語や定型文を登録できます。SimejiのJSON辞書と、UTF-8／UTF-16のタブ区切り辞書を読み込めます。既存の辞書を保持し、重複を除いて登録します。1文字や英字の読みも候補から選べます。[辞書の仕様](docs/ANDROID_USER_DICTIONARY.md)を参照してください。

学習用では、編集前後の記録をPCへ取得し、「誤字」「誤字ではない」「保留」を確認できます。個人向けのローマ字補正規則は端末に別途配置するもので、他の利用者へ配るAPKやソースに同梱しません。未確認の記録を自動で補正に使いません。[収集と確認の手順](docs/ANDROID_TYPO_LEARNING.md)を参照してください。

## プライバシー

入力・変換・学習は端末内で処理し、**インターネット権限を要求しません**。GboardやWindowsのGoogle日本語入力のプログラム・辞書・学習履歴とは連携しません。

パスワード・数字・電話番号などの欄では変換と学習を行いません。数字・電話番号欄のクリップボードだけは明示的な貼り付けに対応します。入力先アプリが学習禁止を指定した欄では、個人補正・予測・文脈別学習を停止します。学習をOFFにしても既存の辞書・履歴は保持します。

通常の入力欄では、句読点の判定と文脈別学習のため、カーソルの前最大128文字・後最大64文字を一時参照します。参照文そのものを診断ログや外部へ送信しません。学習・収集の保存内容と除外条件、削除方法は[SECURITY.md](SECURITY.md)に記載しています。

キーボードを有効にする際、Androidは入力内容へのアクセスについて警告します。パスワード欄などの検出は入力先アプリの指定に依存します。

## 開発と検証

.NET 10とAndroid SDK／JDKを使います。両ABIのMozcとOSS辞書を先に用意してください。[ビルドと導入](docs/ANDROID_PROTOTYPE.md)、[エミュレーターの起動・試験](docs/ANDROID_EMULATOR.md)、[表示と操作の仕様](docs/KEYBOARD_APPEARANCE.md)を参照してください。

```powershell
dotnet run --project android/Meltype.Android.Tests
python android/tools/test_keyboard_source.py
dotnet build android/Meltype.Android -t:Rebuild -c Release
# 学習用は -p:TrainingBuild=true を追加
```

本家1.3.0の共通コア511件とAndroidの入力回帰を検証しています。1.3.0を操作へ接続した作業版は実機A142でも確認しました。0.5.0で追加した数字欄のクリップボードと30％のタップ判定はエミュレーターで検証し、実機での押しやすさ・速度とは区別して記録します。最終の検証結果と制限は[0.5.0の変更点](docs/ANDROID_RELEASE_0_5_0.md)を参照してください。
