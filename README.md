# Meltype Android

日英を切り替えずに入力できる、Android向けの日本語キーボードです。QWERTY配列のローマ字入力をライブ変換し、変換の区切りや候補を画面上で調整できます。

現在のバージョンは1.2.0です。端末内AIを使った変換・誤字補正を高速化しました。入力内容をサーバーへ送らず、端末内で処理します。

## インストールする

Android 8.0以降のarm64端末に対応します。x86_64はエミュレーターで検証しています。

1. [最新版のダウンロード](https://github.com/AoneSenbongi/Meltype-Android/releases/latest)を開き、`Meltype-Android-1.2.0.apk`を取得します。
2. APKを開いてインストールします。Androidから求められた場合は、このファイルを開いたアプリにインストールを許可します。
3. Meltypeアプリを開き、「有効にする」でMeltypeを有効にします。
4. 「キーボードを選ぶ」でMeltypeを選び、試し書き欄で入力します。

通常版1.1.0からは上書き更新できます。保存済みの設定・辞書・学習データは引き継ぎます。別アプリとして入れた学習用・検証用のMeltypeからは、データを自動移行しません。

元のキーボードにはAndroidの入力方法切替から戻せます。

## できること

### 日英を混ぜて入力する

日本語と英語を自動判別し、日本語はライブ変換します。候補はキーボード上部に表示され、横にスクロールできます。英語専用の入力にも切り替えられます。

### 変換の区切りを直す

欲しい候補が出ないときは、読みの範囲を変えて候補を取得し直せます。画面のShiftを2回タップして固定し、左右矢印で文節を縮めたり広げたりします。もう一度Shiftをタップすると解除します。

- `に｜だい` → 範囲を`にだい`へ広げる → `荷台`
- `camera` → Shiftを固定して左・右で文節を変更する → `カメラ`

候補をタップすると選んだ文節まで確定し、後ろの文節は編集を続けられます。

![文節を調整する操作例](https://raw.githubusercontent.com/AoneSenbongi/Meltype-Android/android-1.2.0/docs/images/android-1.0.0-boundary.svg)

### 誤入力を補正する

端末内AIが文脈を使って変換・誤字候補を評価します。同じ条件の判定結果を再利用し、補正結果が決まった後の重複する推論を省くことで、処理の待ち時間を減らしています。通常の候補を手動で選ぶ操作も使えます。

AIをOFFにした場合も、既存の誤字規則とキーの境界付近のタッチを使う補正が働きます。タッチによる補正は、同じ段の近隣キーから案が一つに絞れる場合に適用します。キー中央、既知の日本語の読み、明示的な英語指定、学習禁止欄は保護します。曖昧な場合や変換に失敗した場合は元の入力を保持します。

AIと変換の学習が両方ONの場合、未確定の短いローマ字を手動で訂正して確定すると、承認された訂正から個人の誤字傾向を学習します。1回承認された訂正を次回からの補正候補に使い、キーの押し間違い・脱字・重複・順序逆転の傾向を別の語にも応用します。モデルの重みは変更しません。補正には誤りがあり、入力を続けると訂正が戻る場合もあります。長期的な補正精度は未確認です。

### コピーした文を貼り付ける

コピー後に初めてキーボードを開くと、未確定文字や変換候補がなければコピー内容を候補欄に表示します。タップで貼り付けられ、数字・小数・電話番号の配列でも使えます。閉じた後や入力・確定後は同じコピーを再表示しません。

後から貼り付ける場合は、▤で履歴を開きます。×で元の配列へ戻ります。パスワード欄では表示・貼り付けを無効にします。

### 配列や辞書を使い分ける

右寄せ・左寄せの片手表示、文字キーの上フリック・長押しによる数字や記号の入力に対応します。入力先が数字・電話番号を指定した場合は専用配列を表示します。

単語や定型文を登録でき、Simeji JSONとタブ区切りの辞書を取り込めます。予測候補、計算候補、子音の略入力、空白・括弧・スラッシュなどの表記、文脈別の学習、入力したローマ字の表示も設定できます。型番の英数字は変換せずに保持します。

## 基本操作

| 画面上の操作 | 動作 |
| --- | --- |
| 空白キー | 変換・候補選択。未確定文字がなければ空白を入力 |
| 確定キー | 未確定文字を確定。未確定文字がなければ入力先の改行・送信・次へ |
| 候補をタップ | 選択した文節まで確定し、後ろの文節は編集を継続 |
| 左右矢印 | 文節を選択。未確定文字がなければ入力先のカーソルを移動 |
| Shiftを2回タップして左右矢印 | 選択文節の範囲を変更。再度Shiftをタップして解除 |
| 自動・カナ・日英キーを上フリック | ひらがな・カタカナ・半角カタカナ・全角／半角英数字を選択 |
| 文字キーの上フリック・長押し | キー右上の数字・記号を入力 |
| 123／ABCを長押し | 追加記号を選択 |
| 削除キーを長押し | 連続削除 |
| ▤／× | クリップボード履歴を開く／閉じる |
| 「片手」 | 右寄せ・左寄せ・全幅を切替 |

## 1.2.0の変更点と初期設定

端末内AIの判定結果の再利用、誤字補正と文節・通常候補の扱い、タッチ操作を改善しました。アプリ内で更新を確認し、APKをダウンロードできるようにしました。

新規インストール時の主な設定は次のとおりです。設定はMeltypeアプリで変更できます。

| 設定 | 初期値 |
| --- | --- |
| 端末内AI・変換の学習 | ON |
| 計算結果の候補・語句や英単語の予測・英字の社名やサービス名の予測・入力中の候補 | ON |
| 丸括弧を全角にする・括弧の確定後に内側へ移動する | ON |
| かなの後のwを笑いとして残す | ON |
| 表示どおりに確定する | OFF。確定時も必要な再評価を実行 |
| 読点・句点 | 「，」「．」 |
| 通常の空白・片手表示 | 半角・全幅 |

すべての初期値は[初期設定一覧](https://github.com/AoneSenbongi/Meltype-Android/blob/android-1.2.0/docs/ANDROID_DEFAULT_SETTINGS_1_2_0.md)、各設定の使い方は[利用ガイド](https://github.com/AoneSenbongi/Meltype-Android/blob/android-1.2.0/docs/ANDROID_USER_GUIDE.md)を参照してください。配布物にも`DEFAULT_SETTINGS.json`を添付します。

更新時に保存済みの設定は上書きしません。古い設定ファイルに端末内AIの項目がない場合はOFFのままです。設定ファイルを正常に読めない場合はAIと学習をOFFとして扱います。個人の辞書・学習履歴・クリップボードを初期データとして配布することはありません。

## データとプライバシー

入力・変換・学習・AI処理は端末内で行います。通信するのは、アプリ内で更新を確認・ダウンロードするときです。APKのインストールにはAndroid側での許可・確認が必要です。

通常の変換学習では、確定した語句などを端末内に保存する場合があります。個人の誤字学習で保存するのは、訂正前後の短いローマ字と承認回数です。入力文全体や周辺文の編集履歴は保存・送信しません。学習は設定で停止できます。パスワード欄や学習禁止を指定された欄では個人向け処理を制限します。

クリップボード履歴はテキスト最大10件・1時間をメモリー内に保持し、画像・URI・機密指定の項目は取り込みません。保存条件は[SECURITY.md](https://github.com/AoneSenbongi/Meltype-Android/blob/android-1.2.0/SECURITY.md)、個人の誤字学習は[仕様](https://github.com/AoneSenbongi/Meltype-Android/blob/android-1.2.0/docs/ANDROID_PERSONAL_TYPO_LEARNING.md)を参照してください。

## 既知の制限と検証範囲

- 入力途中に表示された訂正が、入力を続けると元に戻る場合があります。意図した訂正先を選べない場合もあります。
- 誤字の再評価は64打鍵、かな漢字変換へ渡す読みは100文字が上限です。長い未確定入力では、変換品質と速度に制限があります。
- かな配列のフリック入力、音声入力、クラウド同期、Gboardの辞書・学習履歴との連携、Androidの再変換UI、GitHubタイトル候補には対応していません。
- 署名済みAPKをA142／Android 16で確認しました。通常版1.1.0からの更新はAndroid 15のx86_64エミュレーターで確認しています。Android 8.x実機と全端末・全アプリでの動作は未検証です。

入力・設定の回帰テスト46群、ソースの検査13件、記号操作の検査3件が通過しています。検証結果は配布物の`VERIFICATION.json`を参照してください。特定条件での検証結果であり、すべての入力の補正精度や表示速度を保証するものではありません。
