# Androidで利用する1.3.0の新機能

## 利用者の要求
2026年10月19日、共通コア更新だけではなく、Androidで使える1.3.0の新機能を実際に操作できるようにするよう依頼された。既存の誤字補正・タップ判定・Shift伸縮・初回クリップボード候補を保持し、管理画面の設定とタッチ操作へ接続する。

## 適用範囲
| 本家の機能 | Androidへの接続 |
|---|---|
| 計算結果・子音略入力の候補 | 設定スイッチ、変換操作と候補タップ |
| 読み「くりっぷぼーど」「ぺーすと」でコピー内容を候補にする | 変換時1回だけ取得。機密クリップと制限入力欄は除外。既存の初回候補とは独立 |
| 語句・英単語の予測、英字の社名・サービス名 | 設定、候補欄の予測、タップ確定、長押しによる学習削除 |
| 全角括弧・括弧内へのカーソル移動・角括弧・全角スラッシュ | 設定と既存記号キー、追加記号メニュー |
| かな+w、全角スペースとShift+Space半角 | 設定と既存キー |
| F6〜F10相当の文字種変更 | 自動・カナ・日英キーの上フリックで5種類の文字種を選ぶ。取消メニュー・取消設定2項目は利用者の指示により削除 |
| 英字中心の入力 | 設定。文字種メニューでひらがな等へ変更できる |
| 前文脈別の英日学習 | 端末内の言語学習と文脈接続。学習禁止・停止を尊重 |
| 入力中の候補・ローマ字表示 | 既存候補欄と設定。既存の候補表示は既定ONを維持 |
| 漢数字・元号・尺貫法・時候・zh等・ローマ字拡張・候補修正 | 共通コアの自動適用と補助辞書をAndroidの変換へ接続 |
| 1文字・英字読みのユーザー辞書 | 既存の辞書画面から利用。回帰試験で確認 |
| Ctrlによる文節伸縮・部分確定・日英切替 | 既存Shift矢印・Enterの部分確定と文字種メニューへ接続 |
| GitHubタイトルの取得 | 未適用。現在の通信権限なし・端末内処理の構成を維持 |
| PCの登録・配布形式・トレイ・OS全体のホットキー・デスクトップ候補ウィンドウの色/位置 | Androidの仕組みが異なるため対象外 |

新しい任意機能は本家同様に既定OFF。従来からの候補表示、表示どおりの確定、括弧の内側移動は現在の既定動作を維持する。管理画面に学習の設定と追加設定を直接配置する。誤字の編集記録・句読点の収集機能は1.0.0に含めない。設定変更は次に入力欄を開いた時点で反映する。2026年10月19日〜20日に作業版をスマートフォンへ上書き適用し、設定保存・操作・保護条件を実機で確認した。Android版1.0.0の配布候補へ含め、公開は具体的な内容の承認後に行う。
