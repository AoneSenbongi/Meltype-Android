# Android版の更新

管理画面の「アプリを更新」からブラウザーで配布ページを開く。1.1.0からzenzを同梱した通常版としてGitHubの最新正式Releaseへ進む。キーボードに通信権限・インストール権限を追加しない。自動の版比較・ダウンロード・インストールは行わない。

1. 「アプリを更新」を押し、現在の版と更新手順を確認する。
2. 配布ページで現在より新しい対象版のAPKをダウンロードする。1.1.0以降はzenz搭載の通常版を選ぶ。
3. APKを開き、Androidの更新確認を承認する。必要な場合だけブラウザーのインストールを許可する。

同じパッケージ名・互換性のある署名と更新可能なversionCodeのAPKを使う。署名変更などで更新できない場合はアンインストールせず配布ページの移行案内を確認する。アプリ側で辞書や学習データを削除しない。1.1.0の署名ローテーションと確認範囲はANDROID_RELEASE_SIGNING.mdとRelease本文を参照する。

ブラウザーがない場合は配布先URLを表示する。公開先はAoneSenbongi/Meltype-Androidに固定し、入力内容・辞書・学習データをURLへ付加しない。リンク先の表示・通信はブラウザーが行う。
