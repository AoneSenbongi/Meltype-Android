# Android版のアプリ内更新

管理画面の「アプリを更新」でGitHubの最新正式Releaseを確認する。更新があれば「更新」でAPKをアプリ専用キャッシュへダウンロードし、Androidの更新確認へ進む。ブラウザーでのAPK探し・手動ダウンロードは不要にする。初回だけAndroidの「この提供元を許可」が必要。自動・無断インストールは行わない。

配布先はAoneSenbongi/Meltype-Android。通常版はMeltype-Android-<version>.apk、学習用版はMeltype-Android-learning-<version>.apkだけを選び、別パッケージへの誘導を防ぐ。最新Releaseに対応APKがなければ更新なしとし、通常版へ切り替える処理は追加しない。学習用の更新を配布するときは、同じReleaseに対応する学習用APKを添付する。

GitHubのasset digest・サイズを確認し、ダウンロード後のSHA256、APKのパッケージ名・versionCode増加・現在の署名を引き継ぐ証明書履歴を照合する。不一致や中断したファイルはインストールに使わない。インストールはPackageInstaller経由でAndroidの確認を必須とし、既存データを保持する上書きだけを扱う。アンインストールやデータ消去は行わない。

更新確認・ダウンロードに通信権限とAPKインストール要求権限を使用する。入力処理は通信せず、入力内容・辞書・学習データを更新リクエストに含めない。公開・Release添付の追加は、具体的な候補を準備して利用者の確認後に行う。手動のアプリ内更新は通常版1.2.0以降に含む。対応する学習用APKの有無はReleaseごとに確認する。

## 更新前に表示する情報

更新候補がある場合は、現在の版と新しい版、GitHub Releaseの説明文をダウンロード前に表示する。説明文はスクロール可能な読み取り専用の文章として表示し、見出し・箇条書き・コードの表記を読みやすく整える。本文のHTMLやスクリプトは実行しない。本文がない場合はその旨とRelease詳細への導線を表示する。取得上限は既存のメタデータ1MiB、表示本文は最大32768文字とし、それを超えた場合は省略を明示する。

更新ボタンは「ダウンロードして更新」と表示し、押すまではAPKを取得しない。通知から開いた場合もこの画面を経由する。プッシュ通知の設計・通信・設定はANDROID_UPDATE_NOTIFICATIONS.mdを参照する。
