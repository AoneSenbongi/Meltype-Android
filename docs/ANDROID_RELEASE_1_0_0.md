# Meltype Android 1.0.0

**日英を切り替えずに入力。変換の区切りも、その場で直せるAndroidキーボード。**

- **文節を直して候補を選ぶ**：「に｜だい」を「にだい」へ広げて「荷台」を選択。英語と判定された `camera` も「カメラ」へ直せます。
- **予測に合わせてタップ判定を調整**：キーの見た目を変えず、次に来そうな文字に合わせて隣接キーとの境界を調整します。
- **コピー内容を1タップで貼り付け**：コピー後の初回だけ候補欄へ表示。数字・小数・電話番号の配列でも使えます。

雪代／Yukishiro氏の[Meltype](https://github.com/yksr-melt/Meltype) 1.3.0を基に、OSS版MozcとAndroid向けの操作を組み合わせた非公式版です。1.0.0は、このAndroid版の初正式リリースです。

## 文節を直す操作

1. ローマ字で入力し、Shiftを2回押して固定します。
2. 左右矢印で選択文節の読みを縮めたり広げたりします。変更した範囲全体の候補を取得し直します。
3. 候補をタップして確定します。後ろの文節は未確定のまま編集を続けられます。

たとえば「に｜だい」を「にだい」に広げると「荷台」を選べます。「ごじ」からの「誤字」「護持」や、英語と判定されたローマ字入力からの日本語変換にも対応します。

![文節の区切りを広げて荷台を選び、cameraをカメラへ直す操作例](images/android-1.0.0-boundary.svg)

## 本家から引き継いだ機能

日英自動判別、共通辞書、文節編集、語句・英単語と社名・サービス名の予測、計算候補、子音の略入力、取消や文字種の操作、記号・空白の設定、文脈別の日英学習、ローマ字・打鍵間隔の表示をAndroidの設定画面とタッチ操作へ接続しています。

計算や文節編集自体は、本家にもある機能です。設定22項目の初期値と操作は[利用ガイド](ANDROID_USER_GUIDE.md)にまとめています。

## Android向けに実装・修正した部分

- OSS版Mozcと辞書の同梱、入力先へのライブ変換・未確定表示。
- 文節の範囲全体の候補取得と、英語誤判定からの文節変更。前の文節を確定した後も後続を編集できます。
- 次文字予測によるタップ判定の調整。同じ段の隣接文字キーに限り、境界を最大30％調整します。
- コピー後1回だけの候補表示、クリップボード履歴、数字配列での貼り付け。
- 数字・電話番号の専用配列、片手表示、長押し操作、単語登録・辞書取り込み。

コピー候補は閉じた後や入力・確定後には再表示しません。後から貼り付ける場合は▤から履歴を開けます。

## 使い始める

Android 8.0以降のarm64端末に対応します。

1. 添付の `Meltype-Android-1.0.0.apk` を開いてインストールします。
2. Meltypeアプリの「キーボードを有効にする」で有効にします。
3. 「キーボードを選ぶ」でMeltypeを選び、試し書き欄で入力します。

配布するREADME.txtに主要機能と基本操作、[利用ガイド](ANDROID_USER_GUIDE.md)に全機能と設定の説明を記載しています。

## データと対応範囲

入力・変換・学習は端末内で処理し、インターネット権限は要求しません。通常の変換学習では確定した語句等を端末内へ保存する場合があります。学習は設定から停止できます。誤字の削除前後の文字を収集する機能はありません。保存対象と除外条件は[SECURITY.md](../SECURITY.md)を参照してください。

フリック・音声入力、クラウド同期、LLMによる自動修正、Gboardの辞書・履歴との連携、Androidの再変換UI、GitHubタイトル候補は未対応です。
