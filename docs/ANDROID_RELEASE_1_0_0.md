# Meltype Android 1.0.0

このForkで初めての正式リリースです。[雪代／Yukishiro氏のMeltype](https://github.com/yksr-melt/Meltype) 1.3.0を基にした非公式のAndroidキーボードで、日英自動判別とOSS版Mozcによる端末内のライブ変換を利用できます。本家とAndroid版の版番号は別です。

## 対応端末と導入

Android 8.0以降のarm64端末に対応します。x86_64はエミュレーターでの検証用です。

1. 添付の `Meltype-Android-1.0.0.apk` を開いてインストールします。
2. Meltypeアプリの「キーボードを有効にする」で有効にします。
3. 「キーボードを選ぶ」でMeltypeを選び、試し書き欄で入力します。

通常版0.4.1との署名一致を検査した上書き更新用APKです。過去の学習用とは別アプリで、データの自動移行はありません。自動更新もありません。削除すると辞書・学習データも消えるため、更新できない場合は先に版番号と配布元を確認してください。

## 入力・変換の機能

- QWERTY配列のローマ字入力で日本語と英語を自動判別し、日本語をライブ変換します。英語専用入力にも切り替えられます。
- 候補をタップして選択文節まで確定し、後ろの文節は編集を続けられます。入力先の未確定範囲でカーソルを前へ移して候補を選び直せます。
- Shiftを2回押して固定し、左右矢印で文節を縮小・拡大します。英語と誤判定された入力も日本語の読みとして変更できます。`camera` はShift＋左・右で読みを戻し、「カメラ」を選べます。
- 「ごじ／goji」がエンジン内で分割されても、「誤字」「護持」など読み全体の候補を選べます。手動で結合した「にだい」からの「荷台」も候補に含めます。
- 次文字予測で同じ段の隣接キーのタップ判定を最大30％調整します。予測確率55％以上で元のキーより高い場合に限り、中央・操作キー・空白領域は変更しません。
- 日英・カナ・自動キーの長押しで、日本語変換、取消、ひらがな・カタカナ・半角カタカナ・全角／半角英数字、部分確定、全体確定を選べます。
- 文字キー長押しの数字・記号、123／ABC長押しの追加記号、連続削除、括弧入力、句読点の選択に対応します。

## 数字・表示・クリップボード

- 整数・負数・小数・数値パスワード・電話番号に応じた配列へ自動で切り替えます。
- 数字・電話番号でもクリップボードを利用できます。パスワード欄では利用しません。貼り付けられる文字は入力先の制限に従います。
- コピー後に初めてキーボードを開いたとき、未確定文字と変換候補がなければコピー内容を候補欄に表示し、1タップで貼り付けられます。閉じた後や入力・確定後は同じコピーを再表示しません。
- ▤から従来のクリップボード履歴を開けます。テキスト最大10件・1時間をメモリー内に保持し、画像・URI・機密指定のクリップは保持しません。
- 片手表示は右寄せ・左寄せ・全幅を切り替え、左右では通常の80％の幅にします。配置は保存されます。

## 辞書と追加設定

単語・定型文の登録、Simeji JSONとタブ区切り辞書の取り込みに対応します。読みが一致する候補に登録語を出し、既存の登録を保持して重複を除きます。ファイル1MB、登録5000件が上限です。

管理画面には22項目の追加設定があります。計算結果、子音の略入力、語句・英単語と社名・サービス名の予測、読みからのクリップボード変換、括弧・記号・空白の選択、取消や文字種変更の対象、ローマ字表示、打鍵間隔表示などを切り替えられます。任意の新機能は初期状態OFFです。設定の意味・初期値・操作例は[全機能ガイド](ANDROID_USER_GUIDE.md)に記載しています。

## 学習・プライバシー

入力と変換は端末内で処理し、通信権限はありません。通常の変換学習では確定語句や言語判定を端末内に保存する場合があります。「変換の学習」をOFFにすると新しい学習と個人向け予測を停止します。入力先が学習禁止を指定した欄や、パスワード等の制限付き入力欄も保護します。

**誤字の編集記録・句読点の収集機能は搭載していません。** 収集画面、削除前後の取得・保存処理、学習用APKのビルド設定を除去しました。個人の辞書・補正規則・入力履歴・LLMは配布物に含めません。保存対象は[SECURITY.md](../SECURITY.md)を参照してください。

## 検証と制限

2026年10月20日に、次を確認しました。

- Android入力回帰27群とソース検査9件、本家1.3.0の試験を現在のコアへ接続した511件が通過。
- Releaseビルドは警告・エラーなし。両ABIのJNI登録とコールバック、Mozcと辞書の同梱、ZIP整合性、通信権限の不在、通常版0.4.1との署名一致を確認。
- Android 15／x86_64エミュレーターの最終APKで、ライブ候補・Space変換の「誤字」「護持」、Shift固定での「誤字」「荷台」「camera→カメラ」、未確定範囲の保持と候補の確定が通過。
- 最終APKの自己診断でJNI辞書・日英混在ライブ変換・句読点・未確定反映・確定が通過。前文節の確定後も後続を未確定で編集できることを実入力で確認。
- 数字6種類のクリップボード・直接入力と30％の予測境界は同じ入力実装の先行ビルドで確認。最終APKでも整数欄の初回コピー候補・履歴・入力・削除・通常配列への復帰が通過しました。

1.3.0の機能をAndroidの操作へ接続した先行作業版は実機でも確認しています。今回の1.0.0の最終APKはエミュレーターでの確認です。

フリック・音声入力、Androidの再変換UI、クラウド同期、Gboardの履歴との連携、LLMによる誤字検出、GitHubタイトル取得には対応していません。エミュレーターの結果は、実機の押しやすさや全アプリでの挙動を保証するものではありません。
