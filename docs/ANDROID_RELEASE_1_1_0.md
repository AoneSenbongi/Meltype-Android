# Meltype Android 1.1.0

zenz-v3.2-smallを同梱し、未変換のローマ字の誤字を端末内AIで見直す機能を追加する。新規導入時・1.0.0からの更新時は既定OFF。設定の「端末内AI／未変換の誤字を見直す」をONにした入力欄だけで実行する。既に試験版でONにしていた設定を強制変更する処理は追加しない。通信権限は追加せず、入力や推論結果を外部へ送信しない。

対象は標準パッケージjp.aonesenbongi.meltype、versionName 1.1.0、versionCode 7、非debuggable。モデルと両ABIのruntime・ライセンスを同梱する。誤字の候補だけを評価し、候補外の自由生成は適用しない。型番末尾の曖昧な部分は別表記を候補に追加するだけで、自動置換しない。

今回の変更は、上フリックでの記号入力、文字種5項目のメニュー、句読点の中央/代替表示、端末の操作領域へ追従する下部余白、英数字型番の保持、設定画面からGitHubを開く更新案内を含む。取消などの旧操作メニューと取消設定2項目は削除した。

署名方式と上書き更新はANDROID_RELEASE_SIGNING.mdのローテーション案を検証する。公開先はAoneSenbongi/Meltype-Android、タグandroid-1.1.0、タイトルMeltype Android 1.1.0。最終APK・ソース・ライセンス・検証結果とRelease本文を準備し、公開前に利用者へ提示する。実機未接続のため、最終署名APKの実機確認は未実施として明示する。
