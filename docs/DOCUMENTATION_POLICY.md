# Android版の製品説明の方針

READMEと公開本文は、初めて読む利用者が用途と強みを判断できる説明にする。

1. 冒頭でMeltypeをAndroidのキーボードとして使えることを最初の売りにする。その後に日英混在入力と、変換の区切りを直して候補を選べる利点を示す。由来や開発履歴から始めない。
2. 主な機能は利用者の操作と結果で説明する。「に｜だい→にだい→荷台」「camera→カメラ」のように具体例を添える。
3. 本家から引き継いだ機能と、Android向けの実装・修正を区別する。文節編集や計算候補をAndroid独自の発明として紹介しない。
4. GitHubではREADME.mdを主な案内にする。README.txtと配布用README.txtにも同じ本文を置く。冒頭に導入手順を置き、主な操作、初期設定、既知の制限を続ける。全設定の説明は利用ガイド、検証手順と結果は開発資料、保存データはSECURITY.mdへ分ける。
5. 導入には現在のAPKと有効化手順を記載する。通常版の上書き更新と、別パッケージの試験版からのデータ移行を区別する。公開文では今回の変更を先に示し、検証範囲と未解決の制限も記載する。
6. 予測タップやクリップボードは、判定確率等の内部数値より先に、入力時にどう使えるかを説明する。詳しい条件は利用ガイドへ置く。
7. 未対応機能は短く明示する。Windows版のモデル・辞書連携等をAndroidの実装として説明しない。
