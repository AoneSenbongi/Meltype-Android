# 句読点と学習の設定

日本語入力の読点は「、」「，」「,」、句点は「。」「．」「.」から個別に選ぶ。9通りの組合せを許可し、初期値は従来の「，」「．」とする。英語専用モードと英語と判定した区間は半角のままにする。Androidの文末推定は維持し、キーの表示と入力に同じ設定を使う。

Windowsの管理画面とAndroidの導入・設定画面に読点・句点の選択と保存、学習状態、「学習を停止／学習を再開」ボタンを追加する。保存後の新しい入力に反映し、アプリの再起動を要求しない。既に表示済みの未確定文字は変更しない。

停止は新しい学習履歴の追加を止める操作であり、既存の履歴や辞書を削除しない。Meltype経由の変換エンジン学習とMeltypeの変換・言語学習を止める。Google日本語入力を直接使う場合の学習設定は変更しない。Androidの学習用版では誤字収集も停止する。再開後も誤字収集の7日間の開始は利用者が別に操作する。

停止時に実行中の学習処理は完了する場合があり、過去の学習は取り消さない。待機中の学習処理は実行前と確定送信前に設定を再確認する。Androidでは入力先の学習禁止指定・秘密入力の保護を優先し、利用者が再開してもその欄では学習しない。

保存先はWindowsでは利用者のLocalAppData/MeltypeNativeGoogle/input-preferences.json、Androidではアプリ専用領域のfiles/input-preferences.json。Android通常版と学習用版の設定は別になる。設定ファイルを読めない場合は既定の句読点を使い、新しい学習を停止する。
