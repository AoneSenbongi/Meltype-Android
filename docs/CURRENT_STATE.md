## 現在の作業

2026年10月7日、実機報告を受けて未公開0.3.0を修正中。候補タップと変換中のEnterは選択中の文節までを確定し、後続文節の候補・読みを残す。修正前に「われわれは宇宙人だ」が全確定されるテスト失敗を再現し、修正後に候補変更・文節確定・後続文節の取消と鈎括弧入力が通過した。通常入力のEnterと日英モード切替は従来の全文確定を維持する。共有コアの184件も通過した。PC版の作業先は変更していない。

キーは54dpのセル全体をタッチ範囲にし、押した時点で入力する。候補欄の上に32dpの文字表示欄を予約し、同じ候補一覧の再作成を省く。記号欄に「」と削除キーを追加。削除は即時に1文字、400ms保持後に60ms間隔で繰り返し、指を離す・取消・範囲外へ移動・入力欄切替・キーボード非表示で止める。実機で感度が改善したかは未確認。

Android APKのビルドは成功した。入力用SDK・NuGetのパスは移動先を指定した。新しいUIのタップ・長押し・高さを検証するエミュレータースクリプトを追加したが、接続端末とエミュレーターがなく未実行。ユーザーは「入力内容から文末を判定し、コンマキーで文末ならピリオド、途中ならコンマ」を選択した。確定後を一律に扱わないことも要求した。ユーザーは確定後もカーソル直前の文章を判定する仕様を承認した。句読点を押した時に入力先から直前128文字を取得し、未確定文字があればそちらを優先する。確定操作そのものは文末条件にせず、取得失敗時はコンマにする。制限入力欄では文字を取得しない。判定対象は保存・送信しない。ユーザーの自動判定要求に沿い、十分な回答待ち時間の後、コンマキーが限定した語尾で文末を推定して全角ピリオドへ切り替える前提を伝えて実装した。非文末と英語モードはコンマを維持する。明示的な記号キーと長押しピリオドは残す。語尾による推定であり、文の意味を理解した判定ではない。GitHubへのpush・公開はしていない。

Android 0.2.0はQWERTYのローマ字入力、日英自動判別、英語専用モードへの切替、Mozcライブ変換、入力中の候補選択を実装する。英字3段と操作1段、数字・記号への切替、専用アイコンと導入画面がある。入力は端末内で処理し、INTERNET権限を要求しない。
