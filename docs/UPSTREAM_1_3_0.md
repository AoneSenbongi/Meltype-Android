# 本家1.3.0とAndroid独自修正の統合

## 要求と範囲
2026年10月19日の利用者依頼により、本家v1.3.0（6310c44b728d5ad88284853f9ef37ea224993b18）のOS共通入力コアと辞書を取り込み、Instagramチャット由来の個人ローマ字補正・候補バー先頭復帰・予測タップ判定、このチャットのShift固定中の文節伸縮・コピー後1回だけの候補表示を合わせて実機A142へ適用する。

Windows・macOS・Linux専用の登録・更新・ホットキーUIはAndroidへ移さない。新規の任意設定は既定値を維持し、有効化する設定を追加する場合はAndroidの管理画面にも置く。外部通信を伴うGitHub候補の取得はAndroidでは有効にしない。Android独自の部分確定、日英モード、句読点設定、学習停止・学習禁止欄、個人辞書と元キー列編集を維持する。

## 統合方法と検証
基準は既存取込のv1.0.3（6703669）。変更前ソースをdistribution/upstream-1.3.0-local/source-before-integration.tar.gzへ退避し、別領域で3方向比較する。競合は共通コア4ファイルで、解決理由と検証結果を本資料へ記録する。入力コア回帰、本家共通試験、署名とAPK内容検査を済ませ、実機の旧APKと私有データを退避してから上書きする。実機で通常変換・誤字補正と削除再入力・学習禁止欄・予測境界・候補バー・Shift伸縮・クリップボード初回表示と再コピー・英語・記号・数字・片手表示・送信後の状態を確認する。個人データを配布物やGitへ含めない。

統合・実機への適用と操作確認は完了した。配布物・証跡はdistribution/upstream-1.3.0-local。

## 競合解決と試験で判明した差
共通コアの新しい機能を採用しつつ、AndroidのLiveCandidateView・SelectClauseAt・CommitSelectedPrefix・個人補正と元キー保持・学習禁止の接続を保持した。共通の学習ON/OFFとAndroidの入力欄ポリシーを両方確認する。新しい句読点形式はAndroidの既存選択を上書きしない。廃止済みのInputSession・PendingInput・UserModelは基準版から未変更と確認して削除した。

1.3.0のローマ字処理では小文字語末nが未確定になるため、Androidの英語表示中にも従来の日本語候補を残す指定をAndroidInputSessionだけで有効にした。カタカナから自動へ戻す際は新しい手動変換フラグも解除し、次の入力で勝手に確定しないことを既存試験で確認した。新しい辞書ではchinamoniの無補正表示に英語のchinaが含まれるため、学習停止・学習禁止・辞書保護の試験は個人規則を渡さない同一版の入力と比較する。個人規則による「ちなみに」の表示・確定、削除再入力、通常語を直さない試験は維持して通過。
