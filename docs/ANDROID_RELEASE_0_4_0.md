Meltypeを基にした非公式Androidキーボードの試作版0.4.0です。元作者は雪代／Yukishiro氏です。

## 変更点

本家v1.0.3の共有入力コアと辞書の更新を取り込みました。「ci→し」、かな入力の判定修正、再変換のコア処理を含みます。Androidの再変換UIとフリック入力は今回の対象外です。

- 上部の「Meltype・日英自動判別」と、重複する入力文字の表示を削除しました。変換候補は残しています。
- 下部に余白を追加し、Androidのキーボード切替ボタンとキーが重ならない配置にしました。
- 未確定文字がないときは、左右矢印で入力先のカーソルを移動できます。入力中は従来の読み・文節移動を維持します。

- ピリオドを入力する状態では、句読点キーの表示も「．」に切り替わります。
- Shiftは1文字入力すると解除されます。他のキーを押した場合も解除します。

## 導入と更新

Assetsの`Meltype-Android-0.4.0.apk`をダウンロードして開いてください。Android 8.0以降のarm64端末が対象です。

公開0.3.0と同じ署名で、上書き更新できます。0.2.0からは署名が異なるため旧版の削除が必要で、学習データも消えます。自動更新はありません。

## 検証と制限

共有コア194件と、文節確定・矢印移動・句読点判定・Shift解除の入力処理試験が通過しました。APKのビルドは警告・エラーなしです。新しい配置の実機・エミュレーター操作試験は未実施で、OSの切替ボタンの押しやすさは端末での確認が必要です。

## 入力データとソース

入力と変換は端末内で処理し、インターネット権限を要求しません。句読点キーの表示更新時に、未確定文字がなければカーソル直前128文字を参照します。取得した文字は保存・送信しません。学習停止設定と入力先アプリの学習禁止フラグへの対応は未実装です。詳細は[セキュリティ文書](https://github.com/AoneSenbongi/Meltype-Android/blob/main/SECURITY.md)を確認してください。

対応するソース、GPL、第三者ライセンス通知を添付します。導入方法と画像は[README](https://github.com/AoneSenbongi/Meltype-Android)を参照してください。READMEの画像は0.2.0のもので、今回の配置を示す画像は未掲載です。
