Meltypeを基にした非公式Androidキーボードの試作版0.4.0です。元作者は雪代／Yukishiro氏です。

## 変更点

- Shiftは1文字入力後に解除します。他のキー操作や入力先の切替でも解除します。
- キーボード下部に余白を追加し、Androidのナビゲーション領域との重なりを避ける配置にしました。上部の状態表示と重複する入力文字の表示を削除し、変換候補は残しました。
- 句読点キーは、入力する状態に合わせて「，」「．」の表示を切り替えます。
- 未確定文字がないときは、左右矢印で入力先のカーソルを移動できます。
- 本家v1.0.3の共有入力コアと辞書更新を取り込みました。「ci→し」などの修正を含みます。Androidの再変換UIとフリック入力は含みません。

## 導入と更新

Assetsの`Meltype-Android-0.4.0.apk`をダウンロードして開いてください。Android 8.0以降のarm64端末が対象です。

0.3.0からは上書き更新できます。0.2.0からは署名が異なるため旧版の削除が必要で、学習データも消えます。自動更新はありません。

## 検証と制限

共有コア194件と、Shift解除・文節確定・カーソル移動・句読点判定の入力処理試験が通過しています。APKはビルド済みです。新しい配置の実機・エミュレーター操作試験は未実施で、端末ごとの位置や押しやすさは未確認です。READMEの画像は0.2.0のものです。

入力と変換は端末内で処理し、インターネット権限を要求しません。句読点の表示更新ではカーソル直前128文字を一時参照し、保存・送信しません。学習停止設定と入力先アプリの学習禁止フラグへの対応は未実装です。

対応ソース・GPL・第三者ライセンス通知を添付します。詳しくは[README](https://github.com/AoneSenbongi/Meltype-Android)と[セキュリティ説明](https://github.com/AoneSenbongi/Meltype-Android/blob/main/SECURITY.md)を参照してください。
