# 誤字の収集と確認

削除前と打ち直し後の文字を比較し、利用者が後から「誤字」「誤字ではない」「保留」を選ぶ。未確認の記録は自動修正に使わない。まず7日間を試用期間とする。日数は精度を保証する条件ではなく、実際の記録を見て延長を判断する。

## Android

起動時のJava／.NETコールバック登録の不具合を避けるため、ビルド時に `AndroidEnableMarshalMethods=false` を指定する。配布前にUSB接続した実機で `android/tools/Test-DeviceStartup.ps1` を実行し、設定画面の起動とMozc変換が完了することを確認する。試験は学習用アプリの試し書き欄だけを使い、収集を開始しない。

通常版とは別の学習用パッケージ `jp.aonesenbongi.meltype.learning` を用意する。収集は初期状態で停止し、利用者が開始すると7日後に止まる。停止・削除を設定画面から行える。削除操作の前にカーソル直前の最大64文字を一時保持し、打ち直して変換・確定した時の直前文字と組にして保存する。単なる削除と同じ文字への復元は記録しない。入力欄の切替や検出できたカーソル移動では記録を破棄する。記録は編集例であり、誤字と断定しない。最大5000件。上限到達後は追加しない。

パスワード、数値・電話番号・日時、メールアドレス・URI、学習禁止を指定した入力欄は収集しない。学習禁止を指定した欄ではMozcの学習も止める。アプリ名、クリップボード、全入力のログは保存しない。端末の入力欄の指定に依存するため、機密情報を入力する時は利用者が収集を停止する。

保存先はアプリ専用領域の `files/typo-training/events.jsonl`。外部送信とクラウド同期はしない。USBから取得するため、学習用APKのみデバッグ可能にする。USBデバッグを許可したPCはこの記録を読める。通常版には収集画面と取得機能を含めない。

## PC

`android/tools/typo_review.py` を起動している間、USB接続を15秒間隔で確認する。ADBのUSB指定で取得し、複数端末がある時は取得しない。取得済みIDを重複登録しない。データと利用者の判定はソースの外の `E:/Prog/Meltype/Android/training-data` に保存する。

一覧は同じ編集の回数順に並べ、検索と判定別の絞り込みを用意する。判定は後から変更できる。「誤字」だけを別ファイルへ書き出せる。書き出しは自動修正への適用やGitHubへの公開を意味しない。個人データは公開しない。

確認画面はPCの127.0.0.1でのみ動作し、外部ライブラリや通信を使用しない。端末からPCへ取得した後も端末の記録は残す。削除は両方で個別に行う。PC側の一覧を削除する時は確認画面を終了して保存フォルダーを削除する。

## 制限

収集するのは入力欄に表示された文字で、キー操作の全履歴ではない。素早い連続入力や入力先アプリの応答によって一部の編集を取得できない場合がある。空白・句読点だけの打ち直しは誤字記録として収集しない。入力欄を離れる前に確定しなかった編集は破棄する。文脈の意味判定や個人向け自動修正は、確認済みのデータが集まった後に別途設計する。

## 試用手順

1. 学習用APKをインストールし、「Meltype 学習用」を有効にして選択する。通常版の学習データとは分かれる。
2. 学習用アプリの「7日間の収集を開始」を押す。普段どおり入力し、打ち直した後にSpace・確定・候補選択を行う。
3. PCで `android/tools/Start-TypoReview.cmd` を開いたままUSB接続する。スマートフォンのUSBデバッグ接続許可を確認する。PC画面は閉じても取得処理が動くので、終了時は起動したウィンドウでCtrl+Cを押す。
4. 一覧から「誤字」「誤字ではない」「保留」を選ぶ。同じ編集の記録はまとめて判定する。7日後に記録の件数と内容を確認して、継続するか判断する。

ランチャーは現在のPCにあるPythonを使用する。別PCではPython 3とAndroid SDK Platform Toolsを用意し、`python typo_review.py --adb <adbのパス> --data <保存先>` を実行する。通信のないPC内の確認用アプリであり、ブラウザーを閉じただけでは停止しない。

ビルドは既存のAndroid環境を使い、通常のReleaseビルドに `-p:TrainingBuild=true` を追加する。学習用版番号は `0.4.0-learning`。通常版のAPKは `TrainingBuild` を付けずに作成し、デバッグ可能にしない。

## 句読点の入力例

学習用版の収集期間中に、通常の日本語入力で読点・句点を入力した場合も記録する。カーソル直前の最大64文字と実際の句読点を保存し、誤字記録と同じ合計5000件・7日間・停止設定・入力欄の除外条件を使う。クリップボードの貼り付け、英語入力と制限付き入力は対象外。PCの確認画面では句読点の例として区別し、「適切」「不適切」「保留」で判定する。誤字の書き出しには混ぜない。まず収集と確認を行い、予測処理への自動適用はしない。
