# Android試作版

Androidのキーボードとして選択する独立したアプリを作る。Windows版のプログラムは変更しない。QWERTYでローマ字入力し、Meltypeの日英判別とMozcのライブ変換を使う。文字は使用中のアプリの入力欄へ未確定文字として表示する。

## 構成

日英判別と入力処理は既存の`Meltype.Core`を共有する。Androidの`InputMethodService`から専用スレッドで入力処理を呼び、`InputConnection`で表示・確定する。入力欄が変わった後は古い処理結果を送らない。候補をタップすると選択中の文節までを確定し、後続文節を未確定で残す。

変換にはOSS版MozcのJNIライブラリとOSS辞書を同梱する。Gboardのプログラム・辞書・学習履歴は使わない。インターネット権限を要求しない。パスワード欄と数字入力欄は直接入力とし、変換・学習を行わない。

対象はAndroid 8.0以降、arm64の実機とx86_64のエミュレーター。フリック、音声入力、絵文字専用画面、Gboardからの学習データ移行は試作の対象に含めない。

## 0.2.0の画面改善

ランチャーには専用のアダプティブアイコンを付ける。導入画面は有効化・選択の状態、2段階の設定ボタン、試し書き欄をまとめ、端末の密度に合わせた余白とスクロールに対応する。

キーボードはSimejiのQWERTY配置を参考に、英字3段と操作1段にまとめる。文字キーの幅をそろえ、数字と記号は「123」で切り替える。Shiftと削除を英字下段、日英切替・空白・矢印・確定を最下段に置く。Shift時はキーの表示も大文字にする。日英ボタンには現在のモードを表示する。ローマ字入力と日英切替の挙動は維持する。

ライブ変換中も候補を上部の横スクロール欄に表示する。入力中は最後の日本語文節の候補を出す。0.3.0ではタップすると選択中までを確定し、後続文節は未確定で残す。Spaceで変換した後は選択中の文節の候補を表示する。候補を表示するだけでは入力を確定しない。

キーボード下部にはAndroidのナビゲーション領域に応じた余白を確保し、空白・確定キーとシステムのボタンが重ならないようにする。

## 次版の修正方針

候補のタップと変換中の確定は、選択中の文節までを確定し、後ろの文節を未確定で残す。矢印で文節を選び直せる。通常入力中のEnterはこれまでどおり全文を確定する。

文字キーはセル全体をタッチ範囲とし、押した時点で入力する。入力の表示用に候補欄の上へ専用の高さを確保し、入力先と重ねない。同じ候補一覧を毎回作り直さず、表示更新の負荷を減らす。記号配列へ「」を追加する。削除は押した時点で1文字、400ms保持後は60ms間隔で繰り返し、指を離したとき・取消・入力欄切替で止める。句読点キーは「です・ます・だ・ない」などの限定した語尾で文末を推定し、文末なら全角ピリオド、それ以外ならコンマを入力する。意味を理解した判定ではない。ピリオドの長押し入力と記号欄の明示的なコンマ・ピリオドも残す。

## ビルド手順

候補がないときだけ候補欄の右端にキーボードを閉じるボタンを表示する。候補があるときは隠して候補欄へ幅を戻す。閉じる際は未確定の入力を保持するため確定し、長押し削除を止めてからキーボードを隠す。

確定後も句読点キーを押した時点のカーソル直前128文字を入力先から取得し、未確定文字がある場合はそちらを優先して判定する。確定操作そのものは文末の条件に含めない。入力先が直前の文字を返さない場合はコンマにする。パスワード・数字欄では取得しない。取得した文字は今回の判定だけに使い、保存・送信しない。

GitHub Actionsの`Android prototype`をこの専用リポジトリの`main`ブランチで実行する。固定したMozcのソースからJNIライブラリと辞書をビルドし、.NET 10のAndroidアプリへ同梱する。APKと対応するソース、ライセンス通知をArtifactsから取得できる。初回はMozcのビルドに時間がかかる。

## 導入

1. [Android試作版0.4.0のRelease](https://github.com/AoneSenbongi/Meltype-Android/releases/tag/android-prototype-0.4.0)から`Meltype-Android-0.4.0.apk`をAndroidへダウンロードする。APKを開いたアプリに対してインストールを許可する。
2. Meltypeのアプリを開き、「キーボードを有効にする」からMeltypeを有効にする。
3. 「キーボードを選ぶ」でMeltypeを選択する。
4. アプリ内の試し書き欄で`kyouhagoogledekensaku`を入力する。

変換・候補はSpace、確定はEnterまたは候補のタップ。日英切替ボタンを押すと英語だけの直接入力になり、もう一度押すとMeltypeの日英自動判別へ戻る。切替前の未確定文字は確定して残す。日本語の句読点は全角の「，」「．」。通常のキーボードへ戻す場合はAndroidの入力方法選択を使う。

## 確認事項

0.2.0は本家Meltype 1.0.1の修正を含む。旧0.1.0は取り込み前のAPK。0.2.0の公開はエミュレーターでの入力と実際のキー操作のテストが通った後に行う。

APKのビルドと日英切替などの入力テストが通った。Android 15のx86_64エミュレーターで、Mozcの接続、日英混在、句読点、入力欄の未確定表示と確定を確認した。実機での入力速度、各アプリのカーソル・改行・画面回転、長時間入力は別途確認が必要。これらの確認前は試作版として扱う。

0.2.0はエミュレーターで実際のキーを操作し、ライブ候補の表示、Space後の候補選択、数字・記号切替、Shiftの表示、英語専用モードへの切替を確認して公開した。スクリーンショットはReleaseへ添付する。ライブ候補の選択で他の文節と英語部分を保持する挙動は入力処理の回帰テストでも確認した。

署名は試作用。自動更新は行わない。今後、署名が変わる版への更新では再インストールが必要になる場合がある。

MeltypeのGPLと元作者の表記を維持する。Mozcと同梱辞書・依存ライブラリの通知はアプリ内のライセンス画面と配布物へ含める。

## 0.4.0のUI修正（公開準備中）

上部の状態表示、入力方法選択ボタン、重複する未確定文字の表示欄を削除する。候補欄は残す。下部の余白は24dpにナビゲーションバーのInsetを加えて確保し、Androidの入力方法切替ボタンとキーが重ならないようにする。未確定文字がないときの左右矢印は入力先へDPADの押下・解放を送る。入力中の読み・文節移動は維持する。英語専用モードと直接入力欄でも左右移動を使える。
