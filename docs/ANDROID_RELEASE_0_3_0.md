Meltypeを基にした非公式Androidキーボードの試作版0.3.0です。元作者は雪代／Yukishiro氏です。

## 変更点

- 文節を確定すると後続文節まで確定される不具合を修正しました。「我々は宇宙人だ」で「我々は」を確定しても、「宇宙人だ」の変換を続けられます。選択した文節より前の文節は一緒に確定します。
- キーのセル全体でタッチを受け付け、押した時点で入力するようにしました。未確定文字の表示欄を候補欄の上に設け、同じ候補一覧の作り直しを減らしました。
- 記号欄に「」を追加しました。バックスペースは長押しで連続削除できます。
- 「，」キーは入力中の文字、確定後はカーソル直前の文字から文末を推定し、文末なら「．」、途中なら「，」を入力します。確定しただけでは文末扱いにしません。語尾による推定のため誤判定があります。長押しで「．」を入力する操作も残しています。
- 候補がないときは候補欄の右端にキーボードを閉じるボタンを表示します。未確定文字があれば確定してから閉じます。

## インストールと旧版からの移行

対象はAndroid 8.0以降のarm64端末です。x86_64はエミュレーター検証用です。

1. Assetsの`Meltype-Android-0.3.0.apk`をダウンロードします。
2. 公開済み0.2.0とは試作用の署名が異なり、上書き更新できません。旧版を削除するとMeltypeの学習データも消えます。データを残したい場合は、この版の導入を見送ってください。
3. APKを開いてインストールし、Meltypeの導入画面でキーボードを有効にして選択します。

自動更新はありません。

## 入力データの扱い

入力と変換は端末内で処理し、インターネット権限は要求しません。句読点キーを押したときだけカーソル直前128文字を文末の推定に使い、保存・送信しません。パスワードや数字などの直接入力欄では取得しません。Gboardの辞書・学習履歴とは連携しません。

## 検証と制限

文節の部分確定、後続文節の候補変更・取消、日英切替、句読点などの入力処理試験と共有コア184件の試験を通過しました。APKのビルドは警告・エラーなしで完了しました。

今回追加したUIの実機・エミュレーター操作試験は未実施です。入力感度の改善、長押し操作、各アプリとの相性は端末での確認が必要なため、試作版として公開します。文末判定は文章の意味を理解する機能ではありません。
