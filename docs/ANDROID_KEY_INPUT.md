# Androidキー入力の互換性

PhoneDesk等から届く通常のAndroidキーイベントを、画面キーボードと同じInput・InputSpace・Specialへ接続する。変換器・現在の設定・文脈処理は既存のAndroidInputSessionを共用する。キー入力専用のモードや設定は設けない。

一般文字欄の印字可能ASCII、Space、Enter、Backspace、左右矢印を受け付け、未確定時には上下矢印とEscを既存の候補・編集処理へ渡す。Shiftはイベントに含まれる状態を使う。Ctrl/Alt/Meta付き、非対応文字、変換器準備前、数値・パスワード・電話番号等の欄はAndroid標準処理へ渡す。受け付けたキーのUpだけを消費し、欄の開始と終了で追跡を破棄する。

物理入力にタッチ情報を付けない。既存の文字種メニューと自動判別を利用し、専用の変換キー割当や送信コマンドは追加しない。回帰では入力経路と機密欄・ショートカット保護、実機ではPhoneDesk経由の通常入力を確認する。
