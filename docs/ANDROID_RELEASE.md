Meltypeを基にした非公式Androidキーボードの試作版0.2.0です。元作者は雪代／Yukishiro氏です。

専用アイコン、導入状態が分かる設定画面、明るい背景と角丸のキーを追加しました。SimejiのQWERTY配置を参考に、英字3段と操作1段へ整理しました。数字・記号は「123」で切り替えます。Shift時はキー表示も大文字になります。本家Meltype 1.0.1の修正も含みます。

ライブ変換中も候補を上部へ表示します。候補をタップすると、他の文節と英語部分を保って確定します。候補欄は横スクロールできます。コンマのキーを長押しするとピリオドを入力します。入力方法の切替は右上のキーボードボタンです。

ローマ字入力で日英自動判別とOSS版Mozcのライブ変換を使えます。「日英」ボタンを押すと「ABC」の英語専用モードになり、もう一度押すと日英自動判別へ戻ります。日本語の句読点は全角の「，」「．」です。フリック入力はありません。

対象はAndroid 8.0以降のarm64端末です。x86_64はエミュレーター検証用です。

1. Assetsの`Meltype-Android-prototype.apk`をAndroidでダウンロードして開きます。
2. APKを開いたアプリからのインストールを許可します。
3. Meltypeアプリの「キーボードを有効にする」で有効にします。
4. 「キーボードを選ぶ」でMeltypeを選択します。

署名は試作用です。旧APKと署名が異なる場合は、旧版を削除してからインストールしてください。旧版の削除ではアプリの学習データも消えます。自動更新はありません。

入力は端末内で処理し、インターネット権限は要求しません。Gboardのプログラム・辞書・学習履歴とは連携しません。パスワード欄と数字入力欄は直接入力です。

入力処理のテスト、AndroidエミュレーターでのMozc接続と入力欄への表示・確定、実際のキー操作による日英混在・句読点・候補選択・日英切替・Shiftの表示を確認したAPKを公開します。画面は添付のPNGで確認できます。実機での入力速度、各アプリとの相性、画面回転、長時間入力は未確認です。
