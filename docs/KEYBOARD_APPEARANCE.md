# キーボードの表示

未公開の新版は、ユーザーが提示したSimejiの配列を維持し、文字キーを白、操作キーを薄い灰色にする。細い灰色の区切り線と黒い文字で表示する。角丸のキー、キー間の余白、影、押下時の陰影とアニメーションを外す。候補欄は白、閉じるボタンは薄い灰色に揃える。選択中の候補と有効なShiftは太字、日英モードは「自動／英語」の文字で区別する。

キーの54dpのタッチ範囲、押下時の入力、削除の長押し、句読点の長押し、配列と下部のナビゲーション余白を保持する。色と表示のみを変更し、収集・変換・辞書の設定や履歴を移行・削除しない。通常版と学習用版へ同じ表示を適用する。

## 入力操作（2026年10月8日）

Shiftは1回で次の1文字、続けて2回で大文字を固定する。固定中は「⇪」で表示し、Shiftを押すと解除する。数字・記号配列で閉じた場合も、次の表示は通常の英字配列へ戻す。記号配列に1段追加し、「()」「「」」「{}」「[]」「【】」「『』」は一組を入力してカーソルを内側へ移す。閉じ括弧単体のキーも保持する。既存の未確定文字は先に確定する。

日本語の未確定文字がある間はモードキーを「カナ」と1行で表示する。押すと未確定文字をカタカナにし、キーを「かな」へ切り替える。再度押すとひらがなへ戻す。未確定文字がない場合は従来の日英自動判別と英語専用モードの切替を維持する。
