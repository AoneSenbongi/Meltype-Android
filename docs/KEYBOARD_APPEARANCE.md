# キーボードの表示

## 記号の上フリックと句読点表示（2026年10月20日、Issue #1）

右上に記号を表示したキーは、押し始めから24dp以上、横移動より上移動が大きいフリックでも同じ記号を1回だけ入力する。450msの長押しと通常タップは維持する。上方向の移動はキー上端を越えても認識し、横・下への範囲外移動や取消では入力しない。先行キーの確定後に残った移動やタイマーでは追加入力しない。括弧の種類選択も長押しと同じ操作を使う。文字種キーの上フリックは後述の専用メニューを開く。削除・テンキーには追加しない。

句読点キーは中央にタップで入力する文字、右上にもう一方の句読点を表示する。文末予測で中央が句点なら右上は読点とし、上フリック・長押しで右上の文字を入力する。日本語では設定した句読点、英語・制限付き入力欄では半角のカンマとピリオドを表示する。この記述は以前の「長押しで常に句点」を置き換える。

## 次の文字の予測と候補欄（2026年10月18日）

英字配列の見た目と寸法を保ち、既存の英語・ローマ字辞書の前方一致から次の文字を予測する。2文字以上の一致で次の文字の割合が55％以上の場合だけ、文字キーの境界から幅18％以内で隣の文字の判定を広げる。キー中央、操作キー、記号・数値配列、パスワード・メールアドレス・URI・学習禁止欄では調整しない。判定先は押し始めに固定し、長押し・取消・複数指の順序を維持する。入力先・カーソル・配列・モード切替と確定で予測文脈を破棄し、入力履歴を保存しない。既存辞書による予測であり、収集した編集例を生のキー列やタップ位置として扱わない。

候補確定、選択文節の変更、表示文字の変更、候補なしから次の候補表示へ移ったときは候補欄の横スクロールを先頭へ戻す。同じ文節で同じ文字の候補番号だけを切り替えた場合は位置を保持する。

## Android操作盤（2026年10月11日）

句読点の選択肢は「，（全角）」「．（全角）」のように全角の説明を括弧で囲む。

Windows版の操作盤に合わせ、白地、黒い文字、細い灰色の枠を使う。大きなロゴ、キャッチコピー、色付きの状態カード、角丸と影を外す。有効化と選択のボタンは横に並べ、辞書、句読点、学習、試し書きを順に配置する。句読点は選択式と保存ボタンを維持する。

学習はオン・オフのスイッチにする。学習用版の7日間の収集もスイッチにし、開始時の記録内容の確認を保持する。取消時はオフへ戻す。学習停止時は収集も停止し、再開時には自動で収集を始めない。収集期限、件数、記録削除の確認を維持し、画面の再表示や状態更新だけでは保存や収集を行わない。

画面とランチャーのアイコンはWindows版の本家由来のmeltype.icoと同じ青地の「あ」を使う。ランチャー用の余白を確保し、テーマ用の単色アイコンも「あ」に揃える。キーボードの表示・入力処理と既存の設定・辞書・収集記録は保持する。

## タッチ入力の順序と移動許容（2026年10月9日）

文字キーを押したまま次のキーを押した場合、先の文字を先に入力する。先のキーを後から離しても、重複入力や長押し記号の追加はしない。単独の長押しは450msで記号だけを入力する。操作キーと句読点も先の文字を処理してから動作する。

キーの端からAndroid標準のタッチ移動許容幅以内のずれでは入力を取り消さない。許容幅を超えた移動、システムからの取消、入力先の変更と非表示では未入力のキーを取り消す。配列、寸法、表示色、長押し割り当てと削除の連続入力は維持する。

未公開の新版は、ユーザーが提示したSimejiの配列を維持し、文字キーを白、操作キーを薄い灰色にする。細い灰色の区切り線と黒い文字で表示する。角丸のキー、キー間の余白、影、押下時の陰影とアニメーションを外す。候補欄は白、閉じるボタンは薄い灰色に揃える。選択中の候補と有効なShiftは太字、日英モードは「自動／英語」の文字で区別する。

キーの54dpのタッチ範囲、押下時の入力、削除の長押し、句読点の長押し、配列と下部のナビゲーション余白を保持する。色と表示のみを変更し、収集・変換・辞書の設定や履歴を移行・削除しない。通常版と学習用版へ同じ表示を適用する。

## 入力操作（2026年10月8日）

Shiftを有効にしてSpaceを押すと、未確定文字や選択中の変換候補を確定してから全角スペースを1文字入力する。通常のSpaceの変換・半角スペース入力を維持する。1回のShiftはSpace後に解除し、大文字固定は維持する。

日英自動判別で末尾を英字として表示している場合、確定キー・Space・キーボードを閉じる操作ではその表示を維持して確定する。openやdataを確定時だけかなへ再判定しない。日本語と英語が混在する入力でも同様に扱う。Spaceの場合は後ろに半角スペースを付ける。明示的に選んだ日本語・カタカナ・全角英字などの候補と、ひらがな・カタカナモードを保持する。

数字入力欄（AndroidのClassNumber）では、1〜9を3列、0を下中央に置くテンキーを表示する。小数点と負号は入力欄が許可した場合だけ表示する。数値パスワードも同じ配列を使い、変換・学習・収集を行わず直接入力する。電話番号欄では同じ配列に「*」「#」を置き、0の長押しで「+」を入力する。削除、左右移動、確定・次へ等の入力欄指定の操作と閉じるボタンを維持する。英字・日英切替・空白・クリップボードはテンキーでは表示しない。通常の文字入力欄へ戻ったらローマ字配列に戻す。数字・通常配列のキー領域は同じ高さにする。

Shiftは1回で次の1文字、300ms以内に続けて2回押すと大文字を固定する。間隔が300msを超える2回目はShiftを解除する。固定中は「⇪」で表示し、Shiftを押すと解除する。数字・記号配列で閉じた場合も、次の表示は通常の英字配列へ戻す。括弧キーは「()」と「「」」へまとめる。前者の候補は()・（）・{}・｛｝・[]・［］、後者は「」・｢｣・『』・【】。押すと既存の未確定文字を確定し、括弧の候補を表示する。Spaceで候補を切り替え、候補タップまたはEnterで括弧を確定してカーソルを内側へ移す。Enterで括弧を確定した後はローマ字配列へ戻す。文字キーを押した場合も括弧を確定して中へ入力する。削除・取消で括弧候補を取り消す。数字・記号は3段と操作1段に戻す。

日本語の未確定文字がある間はモードキーを「カナ」と1行で表示する。押すと未確定文字をカタカナにし、キーを「自動」へ切り替える。再度押すと日英自動判別とライブ変換へ戻す。切替時に文字を確定せず、日本語は漢字を含む変換表示へ戻り、英語と混在入力も自動判別する。未確定文字がない場合は従来の日英自動判別と英語専用モードの切替を維持する。

## 長押し・クリップボード・表示安定化（2026年10月8日）

ローマ字配列の各キーの右上に長押し記号を小さく表示する。Gboardの参考画像を受け、記号は右端・上端から4dp離した24×18dpの領域に11spで表示する。文字の中央位置、キーの寸法と配列、記号の割り当てと括弧の一括入力は維持する。450msの長押しで記号だけを入力し、通常のタップでは文字だけを入力する。長押し候補は数字・一般記号と2種類の括弧グループ。括弧は既存の変換候補を使う。

候補がない時、候補欄にクリップボードボタンを置く。同じボタンを再度押すと一覧を閉じ、開いている間は「×」を表示する。一覧内の「戻る」は設けず、全消去を残す。一覧は文字キーと同じ高さの領域へ表示し、項目をタップして貼り付ける。キーボード表示時と一覧を開いた時に取得したテキストを最大10件、1時間、サービスのメモリー内に保持する。Androidが持つ過去の履歴は取得できない。画像・URI・機密指定のクリップは保持しない。入力先変更と非表示では一覧を閉じる。パスワード等の制限付き入力欄では一覧を無効にする。

下部余白は固定48dpにせず、OSが通知するナビゲーション領域とIME用ボタン領域（API 30以降のcaptionBarを含む）のうち、入力ビューに重なる高さだけを確保する。ウィンドウ下端から入力ビュー下端までの領域はOSが確保済みとして差し引く。Insets通知と表示位置・サイズの変更後に計算し直し、同じ通知を繰り返しても余白を加算しない。OSの領域を取得できない初期状態では固定値を推測せず、レイアウト確定後の通知で反映する。IME専用テーマでナビゲーション背景をキーボードの灰色、操作アイコンを明色背景用に指定する。対応OSではコントラスト用の自動暗幕を外す。OS・メーカー側が強制するアイコン形状や配色は変更しない。端末の入力方法切替・戻るボタンに文字キーや一覧を重ねない。候補・クリップボード・記号切替でキー領域の高さを変えない。矢印操作は入力先の選択位置を直接変更し、サロゲートペアを分断しない。直接変更に対応しない入力先のみ従来のキーイベントを使う。Nothing Phone (2a)とLG Wingの実機での余白・配色は端末上の確認が必要。

記号配列の「()」「「」」は他の記号キーと同じ白にする。操作キーの灰色は文字数で判定せず、Shift・削除・確定・矢印・配列切替・モード・空白と一覧の全消去に適用する。

クリップボードの一覧から選んで貼り付ける操作は[Gboardの案内](https://support.google.com/gboard/answer/10742542?hl=ja)を参考にする。固定保存・画像・部分抽出は今回の対象に含めない。

長押しはNを「!」、Mを「?」とし、記号配列でも「!」「?」を削除キーの左隣へ並べる。長押しの全記号は下記の記号配列と同じ位置に揃え、括弧の一括入力を維持する。

記号配列のキーサイズと位置はローマ字配列に揃える。1段目・2段目は10個の等幅キー、3段目は左端のABC・中央7個の記号・右端の削除とし、ABCと削除は文字キーの1.5倍幅にする。記号は1段目「1234567890」、2段目「@ # ¥ % & - + () / 「」」、3段目「_ ' : ; \" ! ?」に配置する。操作段・候補欄・下部余白の位置と高さは共通とする。句読点は下段の句読点キーへまとめ、記号配列との重複をなくす。句点は文末判定または句読点キーの長押しで入力できる。

ローマ字配列の長押し記号も、この記号配列の同じ位置に揃える。Kは「()」、Lは「/」、右端の「-」キーは「「」」とする。Z・X・C・V・B・N・Mは「_ ' : ; \" ! ?」に揃える。「()」の表示と操作は括弧の一括入力を表し、開き括弧・閉じ括弧の独立した割り当ては設けない。この記述は以前の長押し割り当てを置き換える。

英語専用モードはキーボードを閉じた時に解除し、同じ入力欄でも次に開く時は日英自動モードに戻す。入力欄の開始時も日英自動モードで開始する。

アプリ側で送信・消去・確定し、未確定範囲がなくなった場合はIME内部の未確定入力と候補も破棄する。送信済みの文字を入力欄へ再挿入しない。通常の未確定入力、候補選択と変換範囲末尾のカーソルは保持する。変換範囲の外へ移動した場合も内部入力を破棄する。破棄前に予約された入力結果は世代番号で無効にする。

日英自動モードでは、英語と判定した入力にも変換候補を表示する。ローマ字として読める場合はかな・カタカナ・漢字候補も選べる（kakao → カカオ）。Enter・通常のSpaceによる英字確定と、英語専用モードの直接入力は維持する。未確定範囲内の文字を選ぶと、その文節の候補を表示し、後続の文節を確定しない。

## 片手モード

候補がないときだけ候補欄に「片手」を表示する。押すたびに右寄せ・左寄せ・全幅の順で切り替える。ポップアップと余白の操作ボタンは置かない。片手モードでは候補欄とキー領域の幅を通常の80％にし、高さとキー配列を維持する。反対側は空の余白とする。英字・数字記号・テンキー・クリップボードに同じ配置を適用する。選んだ配置は端末内に保存して再表示時にも使う。候補表示中も選んだ配置を保持し、入力を確定して候補が消えたら「片手」を再表示する。ナビゲーション領域の余白は全幅の下部に保持する。

## 次文字予測・Shiftによる範囲変更・クリップボード候補（2026年10月19日）

次文字予測はInstagram URLがタイトルのチャット（01a14f5b-a176-7bf1-8688-3742c581775f）から引き継ぐ。利用者が合意した「見た目は変えず、予測に応じて判定範囲を調整する」動作を対象とする。既存の次文字辞書と、同じ段の文字キー境界を最大30％調整する実装を検証する。キー中央・操作キー・空白領域へ判定を広げない。

入力開始時にコアが一時的な非表示と未確定表示を続けて返す場合、予測用のキー履歴を途中で消さない。編集結果をまとめて反映した後、未確定入力が実際に空になった時点で履歴を消す。

Shiftが有効な間、左右矢印は未確定の選択文節を1文字ずつ縮小・拡大する。Shiftを2回押した固定中は繰り返し変更でき、Shiftを押して解除すると通常の文節移動に戻る。未確定文字がない場合は通常のカーソル移動を維持する。

コピー後に初めてキーボードを開いたときだけ、変換候補と未確定入力がなければ候補欄へテキストを表示する。同じコピー内容は閉じて開き直しても再表示しない。入力開始・確定・貼り付け後も再表示しない。コピーの時刻を使って新しいコピーを区別し、同じ文字列を再コピーした場合も次の初回表示の対象にする。消費したコピーの時刻だけを端末へ保存し、入力サービスの再起動後も再表示しない。従来のクリップボード一覧からは引き続き貼り付けられる。タップ1回で入力先へ貼り付けるため、一覧を開く操作は不要。変換候補を優先し、機密指定・画像・URIと制限付き入力欄は対象外。長文は表示だけを省略し、貼り付けでは元の内容を保持する。取得したテキストは既存の履歴と同じ件数・有効期限・メモリー内保持の条件を使う。同じ入力欄で閉じて開き直した場合は、その間に新しいコピーがあったときだけ表示する。

履歴の取得時点は、従来の一覧表示時に加えてキーボード表示時とする。画像・URI・機密指定のクリップは引き続き保持しない。

## 1.3.0の新機能の操作
管理画面の「1.3.0の入力機能」に、変換候補・記号と空白・入力操作・学習と表示の共通20項目（端末内AIの設定は別途含む）を直接配置する。変更は次に入力欄を開いたときに反映する。新しい任意機能は既定OFFとし、従来の入力中候補・表示どおりの確定・括弧内への移動は既定ONを維持する。各項目を切り替えても他の設定を変更しない。

自動・カナ・日英キーの上フリックで、ひらがな・カタカナ・半角カタカナ・全角英数字・半角英数字の5項目だけを開く。右上に上方向の印を表示する。このキーの長押しではメニューを開かず、通常タップの切替動作は維持する。取消・日本語に変換・選択文節まで確定・すべて確定のメニュー項目と、取消関連の設定2項目は削除する。123・ABCキーの追加記号メニューと、文字キーの長押し・上フリックは維持する。文字種変更を選択文節だけに適用する設定は残す。

予測変換をONにすると、候補欄に語句・英単語の予測を表示する。社名・サービス名の設定をONにすると読みから英字表記も出す。タップで確定し、長押しで保存された語句を学習から削除する。入力したローマ字の表示も同じ欄で切り替える。キーボード全体の高さ・キー寸法は変えない。

「読みからクリップボードを変換する」がONなら、ぺーすと・くりっぷぼーど等を変換した操作の中で1回だけコピー内容を取得し、候補へ追加する。ライブ候補の再描画では取得しない。これはコピー後にキーボードを初めて開いた時の候補とは独立する。機密クリップ、画像、URI、制限付き・学習禁止入力欄では取得しない。

## 数字専用キーボードのクリップボード（2026年10月20日）
整数・負数・小数・電話番号欄でも候補欄の▤から履歴を開き、コピー後の初回候補をタップして貼り付ける。閉じると元のテンキーへ戻る。入力先の文字制限はAndroidの入力欄へ委ね、クリップボードの文字を勝手に削除・変換しない。数値パスワードを含むパスワード欄ではクリップボードの履歴への取り込み・表示・貼り付けをしない。数字欄では引き続き変換・学習を行わない。

2026年10月20日の利用者の追加要望により、次文字予測の境界調整をキー幅の18％から30％へ拡大する。予測確率55％以上かつ元のキーより高い場合に限り、同じ段の隣接境界だけを調整する。中央・別の段・操作キー・空白領域は変更しない。

## 全体の読みの候補（1.0.0）
「ごじ」がMozcで「ご」「じ」に分かれても、ライブ候補と変換候補へ「誤字」「護持」などを含める。候補の照会専用セッションだけでShift+Right相当の文節拡張を行い、照会した読み全体と完全一致する1文節の候補を取得する。通常の自動文節分割と文脈変換は変更しない。拡張が進まない・読みが変わる・制限回数や2秒の操作期限を超える場合は取得を打ち切り、候補を捏造しない。

## 英語と判定された入力の文節変更（1.0.0）
日英自動モードで英語と判定された入力も、Shift＋左右矢印でローマ字の読みから日本語の文節変更へ入れる。入力は確定せず、変更後の読みの候補を表示する。英語専用モードと、Shiftなしの英字カーソル移動は従来の動作を保つ。候補取得の整理では、通常の自動分割と候補専用の全体読み照会を分け、読みの検証と拡張上限を維持する。

この操作はAndroidの入力セッションだけで有効にする。PC等のホストは従来どおり、英字表示中のShift＋矢印をアプリの範囲選択へ渡す。


## 端末別の下部余白の再計算（2026年10月22日）

## Android 1.2.1のダークテーマ

利用者の依頼により、Androidのダークテーマに合わせてアプリ画面・キーボード・候補欄・クリップボード履歴・文字種メニューとシステムバーの明暗を切り替える。アプリ独自のテーマ選択や画像背景は追加しない。ライトの配色と入力処理は維持する。

実装はmidasdf/Meltype-AndroidのPR #1（head f459e510）を基に、GODANに依存しない配色と構成変更処理を取り出す。表示したまま明暗を切り替えた場合も未確定文字・候補を保持し、固定ボタンも配色を更新する。

明暗の構成変更に伴う同一入力欄の再開では、入力セッションと未確定候補を初期化しない。通常の入力欄変更・終了では従来どおり状態を初期化する。
