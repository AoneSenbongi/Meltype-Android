# キーボードの表示

未公開の新版は、ユーザーが提示したSimejiの配列を維持し、文字キーを白、操作キーを薄い灰色にする。細い灰色の区切り線と黒い文字で表示する。角丸のキー、キー間の余白、影、押下時の陰影とアニメーションを外す。候補欄は白、閉じるボタンは薄い灰色に揃える。選択中の候補と有効なShiftは太字、日英モードは「自動／英語」の文字で区別する。

キーの54dpのタッチ範囲、押下時の入力、削除の長押し、句読点の長押し、配列と下部のナビゲーション余白を保持する。色と表示のみを変更し、収集・変換・辞書の設定や履歴を移行・削除しない。通常版と学習用版へ同じ表示を適用する。

## 入力操作（2026年10月8日）

Shiftは1回で次の1文字、300ms以内に続けて2回押すと大文字を固定する。間隔が300msを超える2回目はShiftを解除する。固定中は「⇪」で表示し、Shiftを押すと解除する。数字・記号配列で閉じた場合も、次の表示は通常の英字配列へ戻す。括弧キーは「()」と「「」」へまとめる。前者の候補は()・（）・{}・｛｝・[]・［］、後者は「」・｢｣・『』・【】。押すと既存の未確定文字を確定し、括弧の候補を表示する。Spaceで候補を切り替え、候補タップまたはEnterで括弧を確定してカーソルを内側へ移す。Enterで括弧を確定した後はローマ字配列へ戻す。文字キーを押した場合も括弧を確定して中へ入力する。削除・取消で括弧候補を取り消す。数字・記号は3段と操作1段に戻す。

日本語の未確定文字がある間はモードキーを「カナ」と1行で表示する。押すと未確定文字をカタカナにし、キーを「かな」へ切り替える。再度押すとひらがなへ戻す。未確定文字がない場合は従来の日英自動判別と英語専用モードの切替を維持する。

## 長押し・クリップボード・表示安定化（2026年10月8日）

ローマ字配列の各キーの右上に長押し記号を小さく表示する。Gboardの参考画像を受け、記号は右端・上端から4dp離した24×18dpの領域に11spで表示する。文字の中央位置、キーの寸法と配列、記号の割り当てと括弧の一括入力は維持する。450msの長押しで記号だけを入力し、通常のタップでは文字だけを入力する。長押し候補は数字・一般記号と2種類の括弧グループ。括弧は既存の変換候補を使う。

候補がない時、候補欄にクリップボードボタンを置く。一覧は文字キーと同じ高さの領域へ表示し、項目をタップして貼り付ける。クリップボードを開いた時のテキストだけを最大10件、1時間、サービスのメモリー内に保持する。Androidが持つ過去の履歴は取得できない。画像・URI・機密指定のクリップは保持しない。全消去と配列へ戻るボタンを用意する。入力先変更と非表示では一覧を閉じる。パスワード等の制限付き入力欄では一覧を無効にする。

下部余白はナビゲーション領域を含めた最大値にし、表示後に二重加算しない。候補・クリップボード・記号切替でキー領域の高さを変えない。矢印操作は入力先の選択位置を直接変更し、サロゲートペアを分断しない。直接変更に対応しない入力先のみ従来のキーイベントを使う。初回表示の沈み込みと白い点滅の解消は実機で確認する。

クリップボードの一覧から選んで貼り付ける操作は[Gboardの案内](https://support.google.com/gboard/answer/10742542?hl=ja)を参考にする。固定保存・画像・部分抽出は今回の対象に含めない。
