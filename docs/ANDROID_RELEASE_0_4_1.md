0.4.0でアプリとキーボードを開けなくなる不具合に対応した修正版です。APKを組み立てる際に起動用の処理が欠ける問題を修正し、配布前の検査を追加しました。

Shiftの1文字入力後の解除と、キーボード配置の改善は維持しています。

0.3.0・0.4.0からは上書き更新できます。アンインストール済みの場合は、APKを入れ直し、Meltypeを有効化・選択してください。削除で消えた学習データは復元されません。0.2.0からは署名が異なるため再インストールが必要です。

APKの再ビルドと両CPU向けの起動用関数の検査は通過しています。修正版の実機・エミュレーターでの起動と入力操作は未確認です。

Android 8.0以降のarm64端末が対象です。対応ソース、GPL、第三者ライセンス通知を添付します。詳しくは[README](https://github.com/AoneSenbongi/Meltype-Android)と[セキュリティ説明](https://github.com/AoneSenbongi/Meltype-Android/blob/main/SECURITY.md)を参照してください。
