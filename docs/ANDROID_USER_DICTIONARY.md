# Androidのユーザー辞書と設定画面

アプリの設定画面で「読み」「単語」を登録し、Androidのファイル選択画面からSimejiのJSON辞書、UTF-8／UTF-16のタブ区切り辞書を取り込む。既存項目を保持し、同じ読みと単語は重複登録しない。改行を含む定型文は保持する。空・改行以外の制御文字・過長の項目は取り込まない。ファイルは1MB、登録は5000件まで。Simejiの日英配列が同一なら1件として扱う。品詞・コメントは保存しない。

保存先はアプリ専用領域のfiles/user-dictionary.json。通常版と学習用版は別の辞書になる。2文字以上の読みはMeltypeのユーザー辞書としてライブ変換と候補へ反映する。1文字読みは文章中を自動置換せず、読みが一致するときの変換候補へ追加する。登録した次の入力欄開始から反映する。Mozcのシステム辞書は変更しない。

設定画面はステータスバー・画面の切り欠き・ナビゲーション・キーボードの領域を避ける。試し書き欄へフォーカスしたときとキーボード領域が変わったときに、試し書き欄の全体が見える位置へスクロールする。通常の閲覧ではスクロール位置を勝手に変更しない。辞書登録欄は学習禁止指定にする。辞書と原本・バックアップは端末とPCの私有領域に保持し、GitHubへ公開しない。
