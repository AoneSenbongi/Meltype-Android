# パスワード・PIN欄のキーボード表示

物理キーボードとして認識されるFIDO2キー等の接続中でも、文字パスワード・表示パスワード・Webパスワード・数字PIN欄ではソフトキーボードを表示する。通常の文字・URL・メール・数字・日付・電話欄はAndroidの物理キーボード設定に従う。

入力種別はクラスとvariationの組み合わせで判定する。数字パスワードのvariation `0x10` は文字クラスのURI、日付クラスの日付にも使われるため、variationだけでは判定しない。

`OnEvaluateInputViewShown`で現在の入力欄を判定し、パスワード・PINならtrue、それ以外は基底クラスへ委譲する。Android 9以降は`OnStartInputView`で表示要求をPostし、入力ビューの世代と現在のパスワード判定を実行時にも確認する。終了済み・変更済みの入力ビューの要求は実行しない。Android 8.xには同APIがないため、表示判定の上書きだけを用いる。

入力欄の開始時に`UpdateInputViewShown`を呼び、パスワードから通常欄へ移った場合も表示を再判定する。既存のパスワード欄の直接入力、学習・予測・クリップボード制限は維持する。新しい設定項目は追加しない。

元の提案: https://github.com/AoneSenbongi/Meltype-Android/pull/3 （midasdf氏）。1.2.1では同提案に入力クラスの判定と遅延要求の失効処理、回帰試験を加える。
