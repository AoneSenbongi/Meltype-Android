# Androidのzenz個人誤字学習

zenzと変換の学習が両方ONで、学習を許可された入力欄だけで動作する。モデルの重みは変更せず、利用者が未確定入力をBackspaceで訂正して日本語として確定した短いローマ字の組をzenzで確認する。手動訂正をzenzが1回承認したら、次回からその利用者の補正候補に使う。適用時もzenzが現在の文脈で元表示と補正候補を比較する。自動補正の結果だけで学習回数を増やさない。

承認した訂正の差分から、押し間違えたキーと正しいキー、抜けたキー、余計なキー、同じキーの重複、隣接2キーの順序逆転を抽出する。キーの置換・脱字・余計なキーは同じキーの編集を別の語へ適用する。重複と順序逆転は別のキーでも候補を作り、同じキーの逆転を優先する。各訂正の承認回数を候補の重みに使い、既知の日本語の読みに直る候補のうち重みが単独で最大のものをzenzへ渡す。同点の別の読みは自動適用しない。例としてarigatpu→arigatouからp→oを学び、未登録のomedetpuにも応用する。全文の組をそのまま置換するだけの学習にはしない。元の入力が正常な日本語・英語なら補正しない。同じ誤字に訂正先が複数ある場合は回数にかかわらず自動適用せず、一般化する傾向の集計からも除く。

対象は4〜32文字の小文字ローマ字で、1文字の追加・削除・置換または隣接2文字の入れ替え。訂正先が既知の日本語の読みで、訂正前が正常な日本語・英語ではない場合だけ扱う。型番・数字・URL・登録語・明示的な英字/かな指定は学習と適用から除外する。入力欄変更・時間切れ・学習OFFで未完了の学習を破棄する。未確定入力を取り消した場合も学習しない。確定後の文章を遡って編集内容を収集しない。

アプリ専用領域のzenz-personal-typos.jsonへ訂正前後の短いローマ字と承認回数を最大256組保存する。周辺文・入力文全体・推論ログは保存しない。同じ誤字に複数の訂正先があれば自動適用しない。一般化したパターンは保存済みの組から導出するため、既存データをそのまま使用する。キーの誤り率やzenzのモデル重みは学習しない。既存の読取専用personal-romaji-typos.jsonと分け、学習OFF時もデータは削除せず使用と更新を停止する。外部送信や共通辞書への反映は行わない。公開済み1.1.0には含まれないローカル実装として検証する。
