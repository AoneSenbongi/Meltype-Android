# Meltype Android 0.5.0

本家Meltype 1.3.0の入力コア・辞書と、Android向けの入力改善をまとめた非公式Android版です。元作者は雪代／Yukishiro氏です。本家とAndroid版の版番号は別です。

## 変更点

- 計算結果、子音の略入力、語句・英単語・英字名の予測、記号と空白、文脈別学習などを設定画面の22項目へ接続しました。新しい任意機能は既定OFFです。
- 日英・カナ・自動キーの長押しで、日本語変換、段階的な取消、文字種変更、部分確定を選べます。123・ABCキーの長押しで追加記号を入力できます。
- 次文字予測によるタップ判定の拡張幅を18％から30％へ広げました。同じ段の隣接キーの境界だけを変更し、中央と操作キーは維持します。
- コピー後初回だけの1タップ候補と履歴からの貼り付けに対応しました。数字・小数・電話番号の専用配列でも利用できます。パスワード欄と機密クリップでは表示しません。
- Shift固定中の矢印で文節を伸縮できます。前の文節を選んで確定した後は、次の文節の候補を左端から表示します。
- 英字・1文字読みのユーザー辞書、個人用ローマ字補正、送信後の入力状態、片手表示などの改善を統合しました。個人の補正規則と入力履歴は配布物へ含めません。
- READMEとセキュリティ説明を、現在の機能・操作・設定に合わせて整理しました。

## 導入と更新

Android 8.0以降のarm64端末が対象です。x86_64は検証用です。通常版はMeltype-Android-0.5.0.apk、学習用はMeltype-Android-learning-0.5.0.apkです。通常版と学習用は別アプリで、辞書・設定も別々です。

通常版0.3.0以降と同じ試作用署名を使う構成です。学習用も既存の同署名アプリへ上書きします。実際の端末での0.5.0上書き確認は未実施です。署名が異なる0.2.0を削除すると辞書と学習データが消えるため、導入前に確認してください。

## 検証結果

検証中。最終APKのビルド・署名・両ABIのMozc・Manifest、Android入力回帰、数字欄の貼り付け、30％の予測境界を確認してから配布候補を確定します。

1.3.0の新機能を操作へ接続した直前の学習用作業版は、実機A142で起動・設定保存・計算・略入力・予測・文字種・取消・記号・空白・英字中心入力・コピー保護と既存機能の回帰が通過しています。今回の0.5.0の追加変更は、利用者の指示によりAndroid 15のエミュレーターで確認します。

## 制限

- LLMによる誤字検出・自動変換は含みません。
- フリック入力、Androidでの再変換UI、GitHubタイトル取得には対応していません。
- エミュレーターの結果は、実機での速度・押しやすさ・長時間入力を保証しません。
- 新しい任意機能は設定で有効にする必要があります。英字名の予測は語句・英単語の予測と併用します。
- 学習用APKはUSB取得のためデバッグ可能です。収集は既定停止で、利用者が開始した場合だけ動きます。

入力は端末内で処理し、インターネット権限を要求しません。詳細は[README](../README.md)、[SECURITY.md](../SECURITY.md)、[1.3.0対応一覧](ANDROID_1_3_0_FEATURES.md)を参照してください。
